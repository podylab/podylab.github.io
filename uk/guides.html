Claude Code Календар Голос і ШІ-чат PoDoo + PoDee

Як відкрити налаштування: запустіть PoDee ще раз із меню «Пуск». Другий острів не з’явиться, відкриються налаштування вже запущеного застосунку.

Claude Code на острові

Острів показує, чим зайнятий агент, і запитує вас, коли агенту потрібен дозвіл.

  1. Відкрийте «Агенти»

    Налаштування → Агенти → Claude Code.

  2. Підключіть обліковий запис

    Кожна тека облікового запису має свій рядок і свою кнопку «Підключити». Якщо облікових записів кілька, натисніть «Підключити всі». Відключати можна по одному.

  3. Перезапустіть сесії

    PoDee додасть хуки до settings.json і збереже копію settings.json.podee-backup. Уже відкриті сесії Claude Code підхоплять їх після перезапуску.

  4. Дивіться біля годинника

    Зовнішній вигляд → «Поруч із годинником»: роботу Claude буде видно прямо на закритому острові.

Календар Google або Outlook

PoDee читає календар за посиланням iCal. Логін і пароль не потрібні.

  1. Додайте календар

    Налаштування → Календар → «Підключити календар». Впишіть назву й посилання iCal.

  2. Посилання з Google

    У Google Календарі: Налаштування → ваш календар → «Інтегрувати календар» → «Секретна адреса у форматі iCal». Вона закінчується на basic.ics. Загальнодоступна адреса підійде, лише якщо календар відкритий для всіх.

  3. Посилання з Outlook

    В Outlook: Налаштування → Календар → Спільні календарі → «Опублікувати календар». Виберіть календар і «Може переглядати всі відомості», натисніть «Опублікувати» й скопіюйте посилання ICS.

  4. Нагадування

    Події оновлюються кожні 15 хвилин. За скільки хвилин нагадати про зустріч, виберіть у «Нагадувати за».

Голос і ШІ-чат

Голосові команди, диктування й запитання до ШІ прямо на острові.

  1. Виберіть розпізнавання

    Налаштування → Голос → Розпізнавання. Whisper на комп’ютері працює без інтернету: модель base важить 150 МБ, small 490 МБ (радимо її), medium 1,5 ГБ. Ще є Whisper у хмарі з безкоштовним ключем Groq і розпізнавання Windows.

  2. Говоріть

    Затисніть Ctrl+Alt+Space і скажіть команду, наприклад «відкрий Telegram». Ctrl+Alt+D вмикає диктування.

  3. Підключіть ШІ-чат

    Налаштування → ШІ-чат → Провайдер. З ключем API: кнопка «Отримати ключ» веде на сторінку провайдера, у Gemini ключ безкоштовний. Без ключа чат працює через підписку: Claude Code, Gemini CLI або Codex.

  4. Де лежать ключі

    У Диспетчері облікових даних Windows, а не у файлі налаштувань.

PoDoo + PoDee

Телефон із PoDoo керує островом: відкриває його, ставить таймер, додає завдання й запитує PoDy.

  1. Встановіть PoDoo

    PoDoo потрібен на комп’ютері й на телефоні. Як встановити

  2. Увімкніть зв’язок

    У PoDee: Налаштування → Модулі → «Зв’язок із PoDoo». Команди приймаються лише від PoDoo на цьому ж комп’ютері.

  3. Керуйте з телефона

    Відкрийте в PoDoo сторінку PoDee: острів відкривається й ховається, таймер і завдання ставляться одним дотиком. Відповідь PoDy приходить прямо на телефон.
