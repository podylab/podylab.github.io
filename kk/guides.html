PoDee нұсқаулықтары

Қадам бойынша: Claude Code, күнтізбе, дауыс пен ЖИ-чат және телефонмен байланыс.

Claude Code Күнтізбе Дауыс және ЖИ-чат PoDoo + PoDee

Баптауларды қалай ашуға болады: PoDee-ні «Бастау» мәзірінен қайта іске қосыңыз. Екінші арал шықпайды, жұмыс істеп тұрған бағдарламаның баптаулары ашылады.

Аралдағы Claude Code

Арал агенттің не істеп жатқанын көрсетеді және агентке рұқсат керек болғанда сізден сұрайды.

  1. «Агенттер» бөлімін ашыңыз

    Баптаулар → Агенттер → Claude Code.

  2. Тіркелгіні қосыңыз

    Әр тіркелгі қалтасының өз жолы мен «Қосу» батырмасы бар. Тіркелгі бірнеше болса, «Бәрін қосу» басыңыз. Өшіруге бір-бірден болады.

  3. Сессияларды қайта іске қосыңыз

    PoDee settings.json файлына хуктар қосып, settings.json.podee-backup көшірмесін сақтайды. Ашық тұрған Claude Code сессиялары оларды қайта іске қосылғаннан кейін алады.

  4. Сағаттың жанынан қараңыз

    Сыртқы көрініс → «Сағаттың жанында»: Claude жұмысы жабық аралда тікелей көрінеді.

Google немесе Outlook күнтізбесі

PoDee күнтізбені iCal сілтемесі арқылы оқиды. Логин мен құпиясөз керек емес.

  1. Күнтізбені қосыңыз

    Баптаулар → Күнтізбе → «Күнтізбені қосу». Атауы мен iCal сілтемесін жазыңыз.

  2. Google сілтемесі

    Google Күнтізбесінде: Параметрлер → күнтізбеңіз → «Күнтізбені біріктіру» → «iCal пішіміндегі жабық мекенжай». Ол basic.ics деп аяқталады. Ашық мекенжай күнтізбе бәріне ашық болғанда ғана жарайды.

  3. Outlook сілтемесі

    Outlook-та: Параметрлер → Күнтізбе → Ортақ күнтізбелер → «Күнтізбені жариялау». Күнтізбені және «Барлық мәліметті» таңдап, «Жариялау» басыңыз, ICS сілтемесін көшіріңіз.

  4. Еске салғыштар

    Оқиғалар әр 15 минут сайын жаңарады. Кездесуді қанша минут бұрын еске салуды «Еске салу» тармағында таңдаңыз.

Дауыс және ЖИ-чат

Дауыс командалары, диктовка және ЖИ-ге сұрақтар тікелей аралда.

  1. Тануды таңдаңыз

    Баптаулар → Дауыс → Тану. Компьютердегі Whisper интернетсіз жұмыс істейді: base моделі 150 МБ, small 490 МБ (соны ұсынамыз), medium 1,5 ГБ. Бұдан басқа, тегін Groq кілті бар бұлттағы Whisper және Windows тануы бар.

  2. Сөйлеңіз

    Ctrl+Alt+Space басып тұрып, команда айтыңыз, мысалы «открой Telegram». Ctrl+Alt+D диктовканы қосады.

  3. ЖИ-чатты қосыңыз

    Баптаулар → ЖИ-чат → Провайдер. API кілтімен: «Кілт алу» батырмасы провайдер бетіне апарады, Gemini кілті тегін. Кілтсіз чат жазылым арқылы жұмыс істейді: Claude Code, Gemini CLI немесе Codex.

  4. Кілттер қайда жатыр

    Баптаулар файлында емес, Windows тіркелгі деректері реттегішінде.

PoDoo + PoDee

PoDoo бар телефон аралды басқарады: ашады, таймер қояды, тапсырма қосады және PoDy-ден сұрайды.

  1. PoDoo орнатыңыз

    PoDoo компьютерге де, телефонға да керек. Қалай орнатуға болады

  2. Байланысты қосыңыз

    PoDee-де: Баптаулар → Модульдер → «PoDoo-мен байланыс». Командалар тек осы компьютердегі PoDoo-дан қабылданады.

  3. Телефоннан басқарыңыз

    PoDoo-да PoDee бетін ашыңыз: арал ашылады және жасырылады, таймер мен тапсырмалар бір басумен қойылады. PoDy жауабы тікелей телефонға келеді.
