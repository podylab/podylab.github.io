PoDee құпиялылық саясаты

2026 жылғы 30 қазаннан бастап күшінде. Pody Lab, podylab@gmail.com

Қысқаша

PoDee компьютеріңізде жұмыс істейді. Pody Lab-тың өз сервері жоқ: біз статистика жинамаймыз, бағдарламаны қалай пайдаланатыныңызды бақыламаймыз және сіз туралы ештеңе алмаймыз. Деректер интернетке тек баптауларда өзіңіз қосқан қызметтерге шығады.

Компьютерде не сақталады

  • Баптаулар, тапсырмалар, жазбалар, алмасу буфері, экран уақыты, хабарландырулар тарихы: Windows профиліңіздегі PoDee қалтасында.
  • ЖИ-ге арналған API кілттері, биржа кілттері және күнтізбелердің жабық сілтемелері: Windows тіркелгі деректері реттегішінде.
  • Мұның бәрі сізде қалады. Microsoft Store нұсқасы деректерін өзімен бірге жояды.

Микрофон

PoDee микрофонды дауыс батырмасын ұстап не басып тұрғанда ғана және өзіңіз қосқан кездесу жазбасы кезінде тыңдайды. Сөз компьютерде (Whisper) немесе баптауларда таңдасаңыз, бұлттық қызметте танылады. Дыбыс сақталмайды, тек мәтін қалады.

PoDee интернетте қайда жүгінеді

  • ЖИ-чат және сөйлеуді тану: сұрақтарыңыз өзіңіз таңдаған қызметке (Anthropic, OpenAI, Google Gemini, Groq, OpenRouter немесе өз мекенжайыңыз) жіберіледі. Деректер сол қызметтің ережелері бойынша өңделеді.
  • Күнтізбе: өзіңіз қосқан Google, Outlook немесе iCal сілтемелері бойынша.
  • Ән мәтіндері: тректің атауы мен орындаушысы LRCLIB (lrclib.net) қызметіне жіберіледі.
  • Ауа райы: қала атауы wttr.in қызметіне жіберіледі. Қала көрсетілмесе, wttr.in оны IP мекенжайы бойынша анықтайды.
  • Портфель: тек оқуға арналған кілттер арқылы Binance, Bybit, OKX қызметтеріне және өзіңіз қосқан әмиян мекенжайлары бойынша ашық блокчейн түйіндеріне сұраулар.
  • Claude лимиттері: Claude Code тіркелгіңіз атынан api.anthropic.com мекенжайына сұрау.
  • Сөйлеуді тану модельдері «Жүктеу» батырмасын басқанда huggingface.co сайтынан жүктеледі.

Интернеттегі кез келген сұраудағыдай, бұл қызметтер IP мекенжайыңызды көреді. Claude Code агенттері оқиғаларды PoDee-ге тек компьютер ішінде (127.0.0.1) береді, олар интернетке шықпайды.
