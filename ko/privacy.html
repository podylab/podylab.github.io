2026년 10월 30일부터 시행. Pody Lab, podylab@gmail.com

요약

PoDee는 내 컴퓨터에서 실행됩니다. Pody Lab에는 자체 서버가 없습니다. 통계를 모으지 않고, 앱 사용을 추적하지 않으며, 나에 대한 어떤 정보도 받지 않습니다. 데이터는 설정에서 직접 연결한 서비스로만 인터넷에 나갑니다.

내 컴퓨터에 남는 것

  • 설정, 할 일, 메모, 클립보드 기록, 스크린 타임, 알림 기록: Windows 프로필의 PoDee 폴더에.
  • AI API 키, 거래소 키, 비공개 캘린더 링크: Windows 자격 증명 관리자에 저장.
  • 이 모든 것은 내 컴퓨터에 남습니다. Microsoft Store 버전은 제거할 때 데이터를 지웁니다.

마이크

PoDee는 음성 버튼을 누르고 있거나 누를 때, 그리고 직접 시작한 통화 녹음 중에만 듣습니다. 음성은 컴퓨터에서(Whisper) 또는 선택한 경우 클라우드 서비스에서 인식됩니다. 오디오는 저장되지 않고 텍스트만 남습니다.

PoDee가 연결하는 곳

  • AI 채팅과 음성 인식: 질문은 선택한 서비스(Anthropic, OpenAI, Google Gemini, Groq, OpenRouter 또는 직접 지정한 주소)로, 그 서비스의 약관에 따라 전송됩니다.
  • 캘린더: 추가한 Google, Outlook, iCal 링크.
  • 가사: 곡 제목과 아티스트가 LRCLIB(lrclib.net)로 전송됩니다.
  • 날씨: 도시 이름이 wttr.in으로 전송됩니다. 도시를 정하지 않으면 wttr.in이 IP 주소로 추정합니다.
  • 포트폴리오: 읽기 전용 키로 Binance, Bybit, OKX, 그리고 추가한 지갑 주소를 위한 공개 블록체인 노드.
  • Claude 한도: Claude Code 계정을 대신해 api.anthropic.com으로 보내는 요청.
  • 음성 모델은 «다운로드»를 누르면 huggingface.co에서 받습니다.

인터넷의 모든 요청처럼, 이 서비스들은 IP 주소를 볼 수 있습니다. Claude Code 에이전트는 PoDee에 이벤트를 컴퓨터 안(127.0.0.1)에서만 보내며, 인터넷으로는 아무것도 나가지 않습니다.

아동

PoDee는 13세 미만 아동을 위한 앱이 아니며, 아동에 관한 데이터를 수집하지 않습니다.
