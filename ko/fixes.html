수정 사항과 새 기능

PoDee 버전별 변경 사항. 업데이트는 자동으로 옵니다.

1.8.0

최신2026-11-08
  • New theme «Orbit»: every word and number made of dots, its own typeface with Cyrillic, one accent colour, dark and light. The island, taskbar, widgets, Settings and the power screen in one style.
  • Power screen in «Orbit»: lock, sleep, shut down, restart or sign out with the arrows or the mouse, with how long the PC has been on.
  • Wallpapers: a gallery that shows each one big before you set it; clouds by day and night, «Eclipse», «Planet», three Minecraft pictures.
  • Taskbar «Over all windows» keeps its strip of the screen: maximized windows no longer go under it.
  • Taskbar: quick settings like Windows 11, a rail on the side edge, tray icons remembered between runs, the AnyDesk icon shows again.
  • Health: its own page, eye exercises with sounds.
  • Widget settings in tabs; options that don't fit the theme are hidden.
  • Charging is lit more calmly: red only below 20 %.

1.7.0

2026-11-06
  • Screenshot: PrtSc or a key of your own freezes every screen, then select a part, mark it up, pin it, print it or pass it on. Nothing is uploaded.
  • Kazakh: 17 languages now.
  • General: one switch shows or hides everything at once, or set the island, widgets and taskbar one by one.
  • Taskbar: the icon of an open app brings up its window instead of a new copy. Clicks work right up to the taskbar's edge.
  • VPN connects and disconnects from the taskbar with one button, with no password window.
  • Blinking tray icons no longer jump around.
  • Drag-selecting on the desktop works with hidden icons too, behind the widgets and the taskbar.
  • Less CPU when idle and less memory.

1.6.2

2026-11-05
  • 아일랜드를 왼쪽, 가운데, 오른쪽 또는 위쪽 가장자리의 원하는 곳에 둘 수 있습니다. 패널 아래쪽 손잡이나 설정에서 옮깁니다.
  • 작업 표시줄: 곡선이 있는 새 모양 «흐름»이 추가되었고, «클래식»은 이제 화면 가장자리에 붙기만 합니다.
  • 배경 없는 작업 표시줄: 모든 받침의 모서리가 같아졌습니다.
  • 설정: 표시기 위치를 간단한 표시로 보여 줍니다.

1.6.1

2026-11-05
  • 두 번째 모니터에 위젯과 아일랜드 배치: 위젯은 화면 가장자리 너머로 끌고, 아일랜드는 패널의 버튼으로 옮깁니다.
  • 「노래 가사」 위젯: 줄이 음악을 따라가고, 가사가 없으면 숨겨집니다.
  • 「설정 옮기기」 페이지: 설정한 모든 것을 파일 하나에 담으며, 키와 비밀번호는 들어가지 않습니다.
  • 아일랜드용 어두운 유리: 배경화면이 비치고, 선택한 색이 색조가 됩니다.
  • 컬러 아일랜드: 어떤 색에서도 글자와 날짜가 잘 보이고, 밝은 색에서는 글자가 어두워집니다.
  • 아일랜드의 통화는 실제 시작 시점부터 세고, 마이크만 잡고 있는 프로그램은 더 이상 통화로 보이지 않습니다.

1.6.0

2026-11-05
  • 독: 모양은 테마대로, 흰색, «자정», 리퀴드 글래스. 전체 너비 또는 내용에 맞춤, 화면 아래 또는 위.
  • 독의 위젯을 클릭하면 바로 위에 패널이 열립니다: 음악, 주간 날씨, 월 달력, 타이머, 부하, 네트워크, 스크린 타임, Claude 한도, 환율, 다운로드.
  • 블록 창이 위젯 창과 같아졌습니다: 섹션, 검색, 카드를 독으로 끌어다 놓기.
  • 스마트 규칙: 회의 전 음악 일시 정지, Claude 주간 한도 경고, 방해 금지 시간, 앱별 규칙.
  • 새 위젯: Gmail, Cursor, 온도, 파일, 스톱워치, 통화, 주식, 하루 타임라인, 플립 시계, YouTube, OpenAI.
  • 고양이의 이름이 바르시크가 되었습니다. 꼬리가 몸에서 자라나 살랑거리고, 음악에 맞추면 더 빨라집니다.
  • 독과 시작의 오른쪽 클릭이 Windows와 같아졌습니다: 관리자 권한으로 실행, 작업 관리자, 파일 위치, 그룹. Claude 한도는 데이터가 없어도 모양을 유지합니다.
  • «보안» 페이지: 키가 저장된 곳, PoDee가 접속하는 곳, 쓰고 있는 메모리와 프로세서 양.
  • 스크립트가 아일랜드에 표시(podee.exe --say), 즐겨 쓰는 앱은 Ctrl+Alt+1…6으로, 전원 모드, 전체 가사와 줄 클릭으로 이동.
  • 16개 언어가 모두 완성되었습니다. 오류, 도움말, 파일 이름도 이제 내 언어로 표시됩니다.

1.5.0

2026-11-04
  • 게임 바: 게임이나 영화가 전체 화면이면 아일랜드 대신 FPS, CPU, GPU, 메모리, 시계, 알림이 있는 얇은 바가 나타납니다. 클릭이 통과하고, 게임에는 아무것도 끼워 넣지 않습니다.
  • 통화: Ctrl+Alt+M은 모든 마이크를 한 번에 끄고, Ctrl+Alt+K는 카메라 거울을 엽니다. 카메라가 켜져 있거나 화면을 녹화하는 동안 아일랜드에 점이 표시됩니다.
  • 위젯 60개 이상: 음악 비주얼라이저, 파형 진행 표시가 있는 «지금 재생 중», 돌아가는 레코드, 시계 문자판, 시간별·주간 날씨, 해와 달, 집중 타이머, 기기 배터리, 부하, Steam 게임, GitHub 1년 등.
  • 어떤 위젯이든 «윤곽선» 배경, 모양, 프레임을 줄 수 있고, «모두에게 같은 모습»은 모든 위젯의 모양을 한 번에 바꿉니다.
  • 아일랜드의 이퀄라이저가 컬러가 되었고, 앨범 커버 색도 쓸 수 있습니다. 소리는 32개 밴드로 나눠 분석합니다.
  • 앱 없이 휴대폰과 파일 주고받기: 선반의 «휴대폰» 버튼이 QR 코드를 보여 줍니다. 휴대폰은 선반의 파일을 받고, 자기 사진과 파일을 «다운로드 → PoDee»로 보냅니다.
  • 스트리머를 위해: 아일랜드에 OBS 녹화·방송 시간과 장면, Twitch나 YouTube 채팅 또는 사이트를 여는 슬라이드 패널, 스포이트, 영역 캡처, 마이크를 포함한 화면 녹화.
  • 독에 «노치» 모양이 생겼습니다. 아일랜드의 «흐름»이 매끄러워졌습니다. 설정에 «게임과 통화» 페이지가 생겼고 Whisper를 삭제할 수 있습니다.
  • 위젯이 더 알기 쉬워졌습니다: 오른쪽 클릭으로 설정이 열리고 그 위젯에 해당하는 항목만 보입니다. 연결이 필요한 위젯에는 설명과 설정 버튼이 있고, 사진은 파일이나 폴더를 고르고 맞춤 방식을 정할 수 있으며, 게이지 색도 직접 고를 수 있습니다. 새 위젯 «지구: 낮과 밤», 부드러운 유리 색조도 추가되었습니다.
  • 블록으로 만드는 독: 시작, 언어, 네트워크, 소리, 배터리, 시계와 위젯 타일(음악, 회의, 타이머, 날씨, 부하, Claude 한도…). 각각 따로 켜고 왼쪽이나 오른쪽에 원하는 순서로 둘 수 있습니다. «위젯» 창은 커졌고 섹션으로 나뉘었습니다.

1.3.9

2026-11-03
  • 작업 표시줄 대신 쓰는 독이 진짜에 더 가까워졌습니다: 구석에 입력 언어와 언어 목록, 앱 메뉴의 앱 이름은 창을 하나 더 엽니다(두 번째 원격 데스크톱). 독의 시작은 언제나 앱을 새로 실행합니다.
  • 시작의 그룹: 아이콘을 다른 아이콘의 가운데에 놓고, 그룹을 열고, 이름을 바꾸고, 아이콘을 가장자리 밖으로 끌어내세요. 오른쪽 클릭 메뉴에 «그룹 만들기», «그룹에 추가», «그룹에서 빼기»가 있습니다. 고정한 앱이 많아도 시작이 위로 밀리지 않습니다.
  • 빠른 설정: 스피커를 한 번 누르면 소리가 꺼지고, Wi-Fi와 VPN 탭에 주변의 모든 네트워크가 보이며, 타일은 첫 클릭에 바뀝니다.
  • «^» 안의 앱은 클릭으로 열리고, 필요한 앱(Steam)은 더블 클릭으로 창이 열립니다.
  • 날씨 출처가 두 곳이 되었습니다: 한쪽이 응답하지 않으면 다른 쪽에서 옵니다. 날씨가 올 때까지 타일에 그렇게 표시됩니다.
  • 최소화된 Telegram과 비슷한 앱이 첫 클릭에 돌아옵니다. 모드를 바꾸면 시작, 휴지통, 시계가 부드럽게 나타나고, «홈»의 시계는 타일 격자에 맞춰집니다.

1.3.8

2026-11-02
  • PoDee가 이 사이트처럼 16개 언어를 지원합니다. 언어는 설정 → 일반에서 고르고, 설치 프로그램도 Windows 언어를 따릅니다.
  • 작업 표시줄 대신 독: Windows 작업 표시줄이 사라지고 독에 검색, 계산기, 모든 앱이 있는 전용 시작과 휴지통, 시계, 배터리, 빠른 설정(Wi-Fi, VPN, 소리, Bluetooth)이 들어갑니다.
  • 독의 창 미리 보기가 바로, 모든 모니터에서 나타납니다. 미리 보기의 ×로 창을 닫습니다. Microsoft Store 앱도 독에 보입니다.
  • 독을 왼쪽이나 오른쪽에 두고 숨길 수 있습니다. 포인터가 가장자리에 닿으면 나옵니다. 배율이 다른 두 번째 모니터에서도 제자리에 있고, Windows가 옮겨도 돌아옵니다.
  • 새 위젯 6종: 큰 시계, 캘린더, 할 일, 메모, 사진, 세계 시계. «위젯» 창에서 모양을 보고 골라 바탕 화면으로 끌어다 놓고, 글자색도 각각 정할 수 있습니다.
  • 파일을 독 아이콘 위로 가져가면 그 앱의 창이 앞으로 나와 파일을 놓을 수 있습니다.
  • 타이머를 휴대폰에서 PoDoo로 취소할 수 있습니다.
  • 화면이 더 이상 깜빡이지 않습니다. PoDee가 창의 포커스를 뺏지 않고, Windows 작업 표시줄은 번쩍임 없이 숨겨지며, 독의 배터리 아이콘에 있는 충전 표시는 잔량과 상관없이 보입니다.

1.3.5

2026-10-31
  • PoDoo 연결(설정 → 모듈). 휴대폰에서 아일랜드를 열고 숨기고, 타이머를 맞추고, 할 일을 추가하고, PoDy에게 물어볼 수 있으며 답은 휴대폰으로 바로 옵니다.
  • 선반이 파일을 변환합니다: 이미지를 JPG, PNG 등으로, 크기 줄이기, PDF로 묶기, 이미지에서 글자 추출, 배경 제거(170 MB 모델은 요청할 때 받습니다). 동영상과 소리는 FFmpeg로. Office가 있으면 문서를 PDF로.
  • 독의 앱에 창이 여러 개면 포인터를 올릴 때 미리 보기가 나타납니다. 이미 앞에 있는 앱을 클릭하면 최소화됩니다.
  • Windows 미디어 서비스가 응답하지 않아도 아일랜드가 더 이상 멈추지 않습니다.
  • Ctrl+Alt+P는 아일랜드를 위로 숨기고 다시 되돌립니다.
  • 설치 프로그램이 업데이트 전에 PoDee를 닫고 끝나면 다시 실행합니다.
  • 알림 영역 메뉴에 «프로젝트 후원» 항목이 생겼습니다.

1.3.4

2026-10-30
  • Whisper가 다시 음성을 인식합니다. 1.3.3에서 새 폴더로 옮긴 뒤 채팅에 Whisper가 설치되지 않았다고 나왔습니다. 같은 이동으로 사라진 자동 시작은 저절로 돌아옵니다.
  • 영어 인터페이스에서는 날씨, 힌트, 음성 오류도 영어로 나오고, AI는 질문한 언어로 답합니다. 언어를 바꿔도 타이머와 뽀모도로가 초기화되지 않습니다.
  • 32비트 Windows용 버전이 나왔습니다.

1.3.3

2026-10-30
  • PoDe의 이름이 PoDee로 바뀌었고, 구름의 이름은 PoDy입니다. 설정, 키, 자동 시작, Claude Code 연결은 저절로 옮겨집니다.
  • 아일랜드의 하트는 Pody Lab 후원 페이지를 엽니다. 옆의 QR 코드로 휴대폰에서도 열 수 있습니다.
  • PoDee를 다시 실행하면 두 번째 아일랜드 대신 설정이 열립니다.

1.3.1

  • 아일랜드를 완전히 숨기고 표시기만 남길 수 있습니다. 표시기에 포인터를 올리면 패널이 열립니다. «일반 → 숨겨졌을 때»에서 켜세요.
  • «물방울», «스프링», «부드럽게», «빠름» 애니메이션이 확실히 달라졌습니다. 고르면 설정에서 바로 재생됩니다.

  • Claude Code 에이전트를 계정별로 끌 수 있습니다.
  • 암호화폐 시세 위젯, 위젯과 독별 투명도.
  • 설정이 깜빡임 없이 열리고, 슬라이더가 끝까지 닿으며, 고양이가 위에서 매달리고 열린 아일랜드 옆에도 있습니다.
