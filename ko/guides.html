Claude Code 캘린더 음성과 AI 채팅 PoDoo + PoDee

설정을 열려면 시작 메뉴에서 PoDee를 다시 실행하세요. 두 번째 아일랜드는 나타나지 않고 실행 중인 앱의 설정이 열립니다.

아일랜드의 Claude Code

아일랜드에 에이전트가 하는 일이 보이고, 권한이 필요하면 아일랜드가 물어봅니다.

  1. «에이전트» 열기

    설정 → 에이전트 → Claude Code.

  2. 계정 연결

    계정 폴더마다 줄과 «연결» 버튼이 따로 있습니다. 계정이 여러 개면 «모두 연결»을 누르세요. 연결 해제는 하나씩 할 수 있습니다.

  3. 세션 다시 시작

    PoDee는 settings.json에 훅을 추가하고 복사본을 settings.json.podee-backup으로 남깁니다. 이미 열려 있는 Claude Code 세션은 다시 시작한 뒤 훅을 받습니다.

  4. 시계 옆에서 보기

    모양 → «시계 옆»: Claude의 작업이 닫힌 아일랜드에 바로 보입니다.

Google 또는 Outlook 캘린더

PoDee는 iCal 링크로 캘린더를 읽습니다. 로그인과 비밀번호는 필요 없습니다.

  1. 캘린더 추가

    설정 → 캘린더 → «캘린더 연결». 이름과 iCal 링크를 입력하세요.

  2. Google 링크

    Google 캘린더에서: 설정 → 내 캘린더 → «캘린더 통합» → «iCal 형식의 비공개 주소». basic.ics로 끝납니다. 공개 주소는 캘린더가 전체 공개일 때만 쓸 수 있습니다.

  3. Outlook 링크

    Outlook에서: 설정 → 일정 → 공유 일정 → «일정 게시». 일정과 «모든 세부 정보를 볼 수 있음»을 고르고 «게시»를 누른 뒤 ICS 링크를 복사하세요.

  4. 알림

    일정은 15분마다 새로 고칩니다. 회의를 몇 분 전에 알릴지는 «미리 알림»에서 고르세요.

음성과 AI 채팅

음성 명령, 받아쓰기, AI에게 묻기를 아일랜드에서 바로.

  1. 인식 방식 고르기

    설정 → 음성 → 인식. PC의 Whisper는 인터넷 없이 작동합니다: base 모델은 150 MB, small은 490 MB(추천), medium은 1.5 GB입니다. 무료 Groq 키를 쓰는 클라우드 Whisper와 Windows 음성 인식도 있습니다.

  2. 말하기

    Ctrl+Alt+Space를 누른 채 «Telegram 열어 줘»처럼 명령을 말하세요. Ctrl+Alt+D는 받아쓰기를 시작합니다.

  3. AI 채팅 연결

    설정 → AI 채팅 → 제공자. API 키가 있으면: «키 받기»를 누르면 제공자 페이지가 열리고, Gemini 키는 무료입니다. 키가 없으면 구독으로 채팅이 작동합니다: Claude Code, Gemini CLI 또는 Codex.

  4. 키가 저장되는 곳

    설정 파일이 아니라 Windows 자격 증명 관리자에 저장됩니다.

Ctrl+Alt+Space음성 명령: 누른 채 말하기

Alt+P아일랜드 열기

Ctrl+Alt+P아일랜드 숨기기와 되돌리기

PoDoo + PoDee

PoDoo가 있는 휴대폰으로 아일랜드를 제어합니다: 열기, 타이머 맞추기, 할 일 추가, PoDy에게 묻기.

  1. PoDoo 설치

    PoDoo는 PC와 휴대폰 모두에 필요합니다. 설치 방법

  2. 연결 켜기

    PoDee에서: 설정 → 모듈 → «PoDoo 연결». 명령은 같은 PC의 PoDoo에서 온 것만 받습니다.

  3. 휴대폰으로 제어

    PoDoo에서 PoDee 페이지를 여세요. 아일랜드 열기와 숨기기, 타이머와 할 일 추가는 한 번의 탭이면 됩니다. PoDy의 답은 휴대폰으로 바로 옵니다.
