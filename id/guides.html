Panduan PoDee

Langkah demi langkah: Claude Code, kalender, suara dengan chat AI, dan koneksi ke ponsel.

Claude Code Kalender Suara dan chat AI PoDoo + PoDee

Cara membuka pengaturan: jalankan PoDee sekali lagi dari menu Start. Tidak muncul pulau kedua, yang terbuka adalah pengaturan aplikasi yang sudah berjalan.

Claude Code di pulau

Pulau menampilkan apa yang sedang dikerjakan agen dan bertanya kepadamu saat agen butuh izin.

  1. Buka «Agen»

    Pengaturan → Agen → Claude Code.

  2. Sambungkan akun

    Setiap folder akun punya baris dan tombol «Sambungkan» sendiri. Kalau akunnya beberapa, tekan «Sambungkan semua». Memutuskannya bisa satu per satu.

  3. Mulai ulang sesi

    PoDee menambahkan hook ke settings.json dan menyimpan salinan settings.json.podee-backup. Sesi Claude Code yang sudah terbuka memuatnya setelah dimulai ulang.

  4. Lihat di samping jam

    Tampilan → «Di samping jam»: pekerjaan Claude terlihat langsung di pulau yang tertutup.

Kalender Google atau Outlook

PoDee membaca kalender dari tautan iCal. Tidak perlu login atau sandi.

  1. Tambahkan kalender

    Pengaturan → Kalender → «Sambungkan kalender». Masukkan nama dan tautan iCal.

  2. Tautan dari Google

    Di Google Kalender: Setelan → kalendermu → «Integrasikan kalender» → «Alamat rahasia dalam format iCal». Akhirnya basic.ics. Alamat publik hanya berfungsi kalau kalendernya terbuka untuk semua orang.

  3. Tautan dari Outlook

    Di Outlook: Pengaturan → Kalender → Kalender bersama → «Terbitkan kalender». Pilih kalender dan «Dapat melihat semua detail», tekan «Terbitkan», lalu salin tautan ICS.

  4. Pengingat

    Acara diperbarui setiap 15 menit. Pilih berapa menit sebelum rapat kamu diingatkan di «Ingatkan sebelum».

Suara dan chat AI

Perintah suara, dikte, dan pertanyaan ke AI langsung di pulau.

  1. Pilih pengenalan

    Pengaturan → Suara → Pengenalan. Whisper di PC bekerja tanpa internet: model base 150 MB, small 490 MB (kami sarankan yang ini), medium 1,5 GB. Ada juga Whisper di cloud dengan kunci Groq gratis, dan Pengenalan Windows.

  2. Bicara

    Tahan Ctrl+Alt+Space dan ucapkan perintah, misalnya «buka Telegram». Ctrl+Alt+D menyalakan dikte.

  3. Sambungkan chat AI

    Pengaturan → Chat AI → Penyedia. Dengan kunci API: tombol «Dapatkan kunci» membuka halaman penyedia, dan kunci Gemini gratis. Tanpa kunci, chat berjalan lewat langganan: Claude Code, Gemini CLI, atau Codex.

  4. Di mana kunci disimpan

    Di Pengelola Kredensial Windows, bukan di file pengaturan.

PoDoo + PoDee

Ponsel dengan PoDoo mengendalikan pulau: membukanya, memasang timer, menambah tugas, dan bertanya ke PoDy.

  1. Pasang PoDoo

    PoDoo perlu ada di PC dan di ponsel. Cara memasang

  2. Nyalakan koneksi

    Di PoDee: Pengaturan → Modul → «Koneksi PoDoo». Perintah hanya diterima dari PoDoo di PC yang sama.

  3. Kendalikan dari ponsel

    Buka halaman PoDee di PoDoo: pulau terbuka dan bersembunyi, timer dan tugas cukup satu ketukan. Jawaban PoDy langsung sampai di ponsel.
