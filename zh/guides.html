分步说明：Claude Code、日历、语音和 AI 聊天、连接手机。

Claude Code 日历 语音和 AI 聊天 PoDoo + PoDee

打开设置的方法：从「开始」菜单再次启动 PoDee。不会出现第二个小岛，而是打开正在运行的程序的设置。

小岛上的 Claude Code

小岛显示智能体正在做什么，需要权限时会询问你。

  1. 打开「智能体」

    设置 → 智能体 → Claude Code。

  2. 连接账号

    每个账号文件夹都有自己的一行和「连接」按钮。有多个账号时，点「全部连接」。也可以逐个断开。

  3. 重启会话

    PoDee 会把钩子添加到 settings.json，并保留一份副本 settings.json.podee-backup。已打开的 Claude Code 会话重启后才会用上钩子。

  4. 在时钟旁查看

    外观 → 「时钟旁边」：Claude 的工作直接显示在关闭的小岛上。

Google 或 Outlook 日历

PoDee 通过 iCal 链接读取日历，不需要账号和密码。

  1. 添加日历

    设置 → 日历 → 「连接日历」。填写名称和 iCal 链接。

  2. Google 的链接

    在 Google 日历中：设置 → 你的日历 → 「集成日历」 → 「iCal 格式的私密地址」。它以 basic.ics 结尾。公开地址只有在日历对所有人公开时才能用。

  3. Outlook 的链接

    在 Outlook 中：设置 → 日历 → 共享日历 → 「发布日历」。选择日历和「可以查看所有详细信息」，点击「发布」，然后复制 ICS 链接。

  4. 提醒

    日程每 15 分钟更新一次。在「提前提醒」中选择提前多少分钟提醒会议。

语音和 AI 聊天

语音命令、听写和向 AI 提问，都在小岛上。

  1. 选择识别方式

    设置 → 语音 → 识别。电脑上的 Whisper 不联网也能用：base 模型 150 MB，small 490 MB（推荐），medium 1.5 GB。此外还有使用免费 Groq 密钥的云端 Whisper 和 Windows 语音识别。

  2. 说话

    按住 Ctrl+Alt+Space 说出命令，例如「打开 Telegram」。Ctrl+Alt+D 开始听写。

  3. 连接 AI 聊天

    设置 → AI 聊天 → 服务商。使用 API 密钥：「获取密钥」会打开服务商页面，Gemini 的密钥免费。不用密钥时，聊天通过订阅运行：Claude Code、Gemini CLI 或 Codex。

  4. 密钥存放在哪里

    在 Windows 凭据管理器中，而不是设置文件里。

PoDoo + PoDee

装有 PoDoo 的手机可以控制小岛：打开它、设置计时器、添加待办、询问 PoDy。

  1. 安装 PoDoo

    电脑和手机上都需要 PoDoo。 如何安装

  2. 开启连接

    在 PoDee 中：设置 → 模块 → 「与 PoDoo 连接」。只接受同一台电脑上 PoDoo 发来的命令。

  3. 用手机控制

    在 PoDoo 中打开 PoDee 页面：打开和隐藏小岛，设置计时器和待办，点一下就行。PoDy 的回答直接发到手机上。
