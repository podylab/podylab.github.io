修复与新内容

PoDee 每个版本的变化。更新会自动推送。

1.6.2

最新2026-11-05
  • 岛屿可以放在左侧、中间、右侧或顶部边缘的任意位置：拖动面板底部的把手，或在设置中选择。
  • 任务栏：新增带弧线的“流动”外观，“经典”现在只贴着屏幕边缘。
  • 无背景任务栏：所有底板的圆角一致。
  • 设置：指示器的位置用简单的标记显示。

1.6.1

2026-11-05
  • 第二台显示器上的小组件和岛屿：把小组件拖过屏幕边缘，用岛屿面板上的按钮移动岛屿。
  • “歌词”小组件：歌词随音乐滚动，没有歌词时自动隐藏。
  • “迁移设置”页面：全部设置都在一个文件里，不含密钥和密码。
  • 岛屿的深色玻璃：透出壁纸，所选颜色成为玻璃的色调。
  • 彩色岛屿：文字和日期在任何颜色上都清晰，浅色背景下文字变深。
  • 岛屿上的通话从真实开始时间计时，只占用麦克风的程序不再显示为通话。

1.6.0

2026-11-05
  • 程序坞：外观有跟随主题、白色、「午夜」和液态玻璃，可选全宽或按内容，放在屏幕底部或顶部。
  • 点击程序坞里的小组件，就会在它正上方打开面板：音乐、一周天气、月历、计时器、负载、网络、屏幕使用时间、Claude 额度、汇率、下载。
  • 方块窗口和小组件窗口一样了：有分区和搜索，卡片可拖到程序坞上。
  • 智能规则：会议前暂停音乐、Claude 每周额度提醒、安静时段、按应用设置规则。
  • 新小组件：Gmail、Cursor、温度、文件、秒表、货币、股票、今日时间线、翻页钟、YouTube、OpenAI。
  • 小猫现在叫巴尔西克：尾巴从身体长出来，轻轻摇摆，跟着音乐会摇得更快。
  • 程序坞和「开始」的右键菜单与 Windows 一样：以管理员身份运行、任务管理器、文件位置、分组；Claude 额度在没有数据时也保持原样。
  • 「安全」页面：密钥存放在哪里，PoDee 连接哪些地址，占用多少内存和处理器。
  • 脚本可在小岛上显示文字（podee.exe --say），常用应用可用 Ctrl+Alt+1…6 打开，电源模式，完整歌词并可点击某行跳转。
  • 16 种语言全部完成：错误提示、帮助和文件名现在都会使用你的语言。

1.5.0

2026-11-04
  • 游戏条：游戏或电影全屏时，小岛变成一条细条，显示 FPS、处理器、显卡、内存、时钟和提醒。点击可以穿透它，不会向游戏注入任何东西。
  • 通话：Ctrl+Alt+M 一次关闭所有麦克风，Ctrl+Alt+K 打开摄像头镜子；摄像头开启或屏幕被录制时，小岛上会显示圆点。
  • 60 多个小组件：音乐可视化、带波形进度的「正在播放」、转动的黑胶唱片、表盘、逐小时和一周天气、太阳与月亮、专注计时器、设备电量、负载、Steam 游戏、GitHub 全年记录等等。
  • 任何小组件都能使用「描边」底板、形状和边框，「统一外观」可以一次改变所有小组件的样子。
  • 小岛上的均衡器变成彩色，还能使用封面的颜色；声音分成 32 个频段。
  • 不用应用就能在手机和电脑间传文件：架子上的「手机」按钮显示二维码，手机下载架子上的文件，也能把自己的照片和文件发到「下载 → PoDee」。
  • 为主播准备：小岛上显示 OBS 录制和直播时间及场景，抽屉面板可放 Twitch 或 YouTube 聊天或任意网站，还有取色、区域截图和带麦克风的录屏。
  • 程序坞有了「刘海」外观；小岛的「流动」形状变得更平滑；设置里新增「游戏与通话」页面，Whisper 可以删除。
  • 小组件更清楚了：右键打开小组件设置，里面只有与它相关的内容；需要连接的小组件有说明和前往设置的按钮；照片可选文件或文件夹以及填充方式；刻度颜色可自定义；新增小组件「地球：昼与夜」；玻璃色调更柔和。
  • 程序坞由方块组成，像拼搭玩具：开始、语言、网络、声音、电池、时钟和小组件磁贴（音乐、会议、计时器、天气、负载、Claude 额度…），每个都可单独开启，按任意顺序放在左边或右边。「小组件」窗口变大了，还有了分区。

1.3.9

2026-11-03
  • 代替任务栏的程序坞更接近真正的任务栏了：角落显示输入语言和语言列表，每个应用菜单里的应用名称可再开一个窗口（第二个远程桌面），程序坞的「开始」总是重新启动应用。
  • 「开始」里的分组：把图标拖到另一个图标中央，打开分组，重命名，把图标拖出边缘；右键菜单有「新建分组」「添加到组」「移出分组」。固定的应用很多时，「开始」不再向上移动。
  • 快速设置：点一下扬声器就能静音，有 Wi-Fi 和 VPN 标签页，周围所有网络都能看到，磁贴第一次点击就切换。
  • 「^」里的应用单击打开，需要的应用（Steam）双击打开窗口。
  • 天气有两个来源：一个没有响应时，就来自另一个；还没拿到时，磁贴会直接说明。
  • 最小化的 Telegram 和类似应用第一次点击就恢复。切换模式时，开始、回收站和时钟平滑出现，「主页」上的时钟与磁贴网格对齐。

1.3.8

2026-11-02
  • PoDee 支持 16 种语言，和本网站一样。在设置 → 常规中选择，安装程序也使用 Windows 的语言。
  • 用程序坞代替任务栏：Windows 任务栏隐藏，程序坞里出现自带的「开始」（搜索、计算器和所有应用）、回收站、时钟、电池和快速设置（Wi-Fi、VPN、声音、蓝牙）。
  • 程序坞的窗口预览立即出现，每台显示器上都有，预览上的叉号可关闭窗口。Microsoft Store 应用也会显示在程序坞里。
  • 程序坞可以放在左边或右边并隐藏：指针碰到边缘时它就滑出来。在缩放比例不同的第二台显示器上它不会移位，被 Windows 挪动后也会回来。
  • 六个新小组件：大时钟、日历、待办、便笺、照片和世界时钟。在「小组件」窗口里按外观挑选，拖到桌面上，每个都能设置自己的文字颜色。
  • 把文件拿到程序坞图标上方，该应用的窗口就会移到前面，方便把文件放进去。
  • 计时器可以通过 PoDoo 在手机上取消。
  • 屏幕不再闪烁，PoDee 不再抢窗口焦点，Windows 任务栏隐藏时不闪一下，程序坞电池图标上的充电闪电在任何电量下都能看到。

1.3.5

2026-10-31
  • 与 PoDoo 连接（设置 → 模块）。在手机上可以打开和收起小岛、设置计时器、添加待办、询问 PoDy，回答直接发到手机上。
  • 架子可以转换文件：图片转 JPG、PNG 等格式，缩小，合成 PDF，提取图中文字，去除背景（170 MB 的模型按需下载）。视频和音频通过 FFmpeg。如果装了 Office，文档可转 PDF。
  • 程序坞里的应用有多个窗口时，指针移上去会显示缩略图。点击已在最前面的应用会将其最小化。
  • Windows 媒体服务停止响应时，小岛不再卡住。
  • Ctrl+Alt+P 把小岛藏到顶部，再按一次恢复。
  • 安装程序会在更新前自动关闭 PoDee，之后重新启动。
  • 系统托盘菜单新增「支持项目」。

1.3.4

2026-10-30
  • Whisper 又能识别语音了。在 1.3.3 迁移到新文件夹后，聊天曾提示未安装 Whisper。同一次迁移中丢失的开机自启会自动恢复。
  • 在英语界面中，天气、提示和语音错误也是英语，AI 用提问的语言回答。切换语言不再重置计时器和番茄钟。
  • 推出了适用于 32 位 Windows 的版本。
