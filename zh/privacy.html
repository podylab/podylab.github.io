PoDee 隐私政策

自 2026 年 10 月 30 日起生效。Pody Lab，podylab@gmail.com

简而言之

PoDee 运行在你的电脑上。Pody Lab 没有自己的服务器：我们不收集统计数据，不追踪你如何使用应用，也不会收到关于你的任何信息。数据只会发往你在设置里自己连接的服务。

留在你电脑上的内容

  • 设置、待办、笔记、剪贴板历史、屏幕使用时间和通知历史：保存在你 Windows 用户目录下的 PoDee 文件夹中。
  • AI 的 API 密钥、交易所密钥和私人日历链接：保存在 Windows 凭据管理器中。
  • 这些都留在你这里。Microsoft Store 版卸载时会删除它的数据。

麦克风

只有在你按住或按下语音按钮时，以及你自己开始的通话录音期间，PoDee 才会听。语音在你的电脑上识别（Whisper），或在你选择时交给云服务识别。音频不保存，只保留文字。

PoDee 会连接哪里

  • AI 聊天和语音识别：你的问题会发送到你选择的服务（Anthropic、OpenAI、Google Gemini、Groq、OpenRouter 或你自己的地址），并受该服务条款约束。
  • 日历：你添加的 Google、Outlook 或 iCal 链接。
  • 歌词：歌曲名和歌手会发送给 LRCLIB（lrclib.net）。
  • 天气：城市名会发送给 wttr.in。如果你没填城市，wttr.in 会根据你的 IP 地址推测。
  • 资产组合：使用只读密钥的 Binance、Bybit 和 OKX，以及为你添加的钱包地址查询的公共区块链节点。
  • Claude 额度：以你的 Claude Code 账号向 api.anthropic.com 发出的请求。
  • 当你点击「下载」时，语音模型会从 huggingface.co 下载。

和任何联网请求一样，这些服务能看到你的 IP 地址。Claude Code 智能体只在你的电脑内部（127.0.0.1）把事件发给 PoDee，不会有任何内容发到网上。

儿童

PoDee 不面向 13 岁以下儿童，也不收集他们的数据。

变更与联系

如果本政策变更，新版本会发布在本页面。联系： podylab@gmail.com.
