如何连接手机

电脑上的 PoDoo 待在系统托盘里。在同一网络下，手机会自动找到它。

  1. 通过 Wi-Fi

    在手机上打开应用。装有 PoDoo 的电脑会出现在列表中：点一下它，确认手机和电脑上的代码相同，然后在电脑上允许连接。

  2. 如果没找到电脑

    点「没找到电脑？」。可以用相机扫描 PoDoo 窗口里的二维码，输入电脑屏幕上的六位数字，或手动填写地址。

  3. 通过 USB 数据线

    插上数据线，在手机上打开「USB 网络共享」。Android 每次拔掉数据线都会关闭它，所以每次都要打开。之后应用会自动找到电脑。

  4. 通过蓝牙

    先在 Windows 设置中把手机和电脑配对。然后在应用第一屏选择蓝牙。首次加载需要几秒钟。

按钮和页面

一切都在电脑上用鼠标设置。手机马上跟着变。

  1. 添加按钮

    按钮可以是应用、网站、文件夹或文件、快捷键、脚本或动作组合。应用直接拖到页面上就行。

  2. 创建动作组合

    把几步操作放进一个按钮：打开项目、播放音乐、关闭通知。

  3. 把页面绑定到应用

    为页面选择应用。其中一个在电脑上处于活动状态时，程序坞会自动切到这一页。没有选择应用时，页面手动滑动切换。

  4. 选择主题

    「素描本」「黏土」「控制台」「海报」「玻璃」等等。也可以设置自己的背景。

PoDoo + PoDee

电脑上装了 PoDee，PoDoo 里就会出现它的页面。在这个页面上可以直接用手机控制 PoDee 小岛。

  1. 安装 PoDee

    需要 PoDee 1.3.5 和 PoDoo 1.0.1 或更高版本。 下载 PoDee

  2. 在 PoDee 中开启连接

    设置 → 模块 → 「与 PoDoo 连接」。PoDoo 里不需要开启任何东西。

  3. 打开 PoDee 页面

    它会自动出现在手机的程序坞里。打开或收起小岛、设置计时器、添加待办、询问 PoDy。PoDy 的回答发到手机上，对话会保存下来。

PoDee 只接受同一台电脑上 PoDoo 发来的命令。

问题

需要账号或联网吗？

不需要账号。手机和电脑只要在同一个局域网里，或者用数据线、蓝牙连接就行。PoDoo 不联网也能用。

电脑上不装程序能用吗？

不能。手机上的应用只是屏幕，动作由电脑上的程序执行。所以电脑程序是必需的。

哪些手机能用？

任何 Android 7.0 及以上的手机或平板。PoDoo 暂时还没有 iPhone 应用。

应用能看到什么？

只用网络和相机，相机仅用于扫描二维码。不会发送任何东西给我们或其他人。

没有 Wi-Fi 能连吗？

能。用 USB 数据线把手机连到电脑，或者用蓝牙配对，然后在应用第一屏选择这种方式。
