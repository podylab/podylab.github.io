手順どおりに：Claude Code、カレンダー、音声とAIチャット、スマホとの連携。

Claude Code カレンダー 音声とAIチャット PoDoo + PoDee

設定を開くには、スタートメニューからPoDeeをもう一度起動します。2つ目のアイランドは出ず、起動中のアプリの設定が開きます。

アイランドにClaude Code

アイランドにエージェントの作業内容が表示され、許可が必要なときは確認が出ます。

  1. 「エージェント」を開く

    設定 → エージェント → Claude Code。

  2. アカウントを接続

    アカウントフォルダーごとに行と「接続」ボタンがあります。アカウントが複数あるときは「すべて接続」を押します。切断はひとつずつできます。

  3. セッションを再起動

    PoDeeはsettings.jsonにフックを追加し、コピーをsettings.json.podee-backupとして残します。開いているClaude Codeセッションは、再起動後にフックを読み込みます。

  4. 時計の横で確認

    外観 → 「時計の横」：Claudeの作業が閉じたアイランドにそのまま表示されます。

GoogleまたはOutlookのカレンダー

PoDeeはiCalリンクからカレンダーを読み込みます。ログインもパスワードも不要です。

  1. カレンダーを追加

    設定 → カレンダー → 「カレンダーを接続」。名前とiCalリンクを入力します。

  2. Googleのリンク

    Googleカレンダーで：設定 → 自分のカレンダー → 「カレンダーの統合」 → 「iCal形式の非公開URL」。末尾はbasic.icsです。公開URLが使えるのは、カレンダーを一般公開している場合だけです。

  3. Outlookのリンク

    Outlookで：設定 → 予定表 → 共有予定表 → 「予定表を公開する」。予定表と「すべての詳細を表示可能」を選び、「公開」を押してICSリンクをコピーします。

  4. リマインダー

    予定は15分ごとに更新されます。会議の何分前に知らせるかは「何分前に通知」で選びます。

音声とAIチャット

音声コマンド、ディクテーション、AIへの質問をアイランドで。

  1. 認識方法を選ぶ

    設定 → 音声 → 認識。PC上のWhisperはオフラインで動きます：baseモデルは150 MB、smallは490 MB（おすすめ）、mediumは1.5 GB。ほかに無料のGroqキーを使うクラウドのWhisperと、Windowsの音声認識もあります。

  2. 話す

    Ctrl+Alt+Spaceを押したまま、「Telegramを開いて」のようにコマンドを話します。Ctrl+Alt+Dでディクテーションが始まります。

  3. AIチャットを接続

    設定 → AIチャット → プロバイダー。APIキーを使う場合：「キーを取得」でプロバイダーのページが開きます。Geminiのキーは無料です。キーなしの場合は、サブスクリプション経由で使えます：Claude Code、Gemini CLI、Codex。

  4. キーの保存場所

    設定ファイルではなく、Windows資格情報マネージャーです。

PoDoo + PoDee

PoDooを入れたスマホでアイランドを操作できます：開く、タイマーをセット、タスクを追加、PoDyに質問。

  1. PoDooをインストール

    PoDooはPCとスマホの両方に必要です。 インストール方法

  2. 連携をオンにする

    PoDeeで：設定 → モジュール → 「PoDooとの連携」。コマンドは同じPCのPoDooからだけ受け付けます。

  3. スマホから操作

    PoDooでPoDeeのページを開きます。アイランドの開閉、タイマーやタスクの追加はワンタップです。PoDyの答えはそのままスマホに届きます。
