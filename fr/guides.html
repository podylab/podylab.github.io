Pour ouvrir les paramètres, relancez PoDee depuis le menu Démarrer. Aucune deuxième île n’apparaît, ce sont les paramètres de l’appli déjà lancée qui s’ouvrent.

Claude Code sur l’île

L’île montre ce que fait l’agent et vous demande quand il a besoin d’une autorisation.

  1. Ouvrez « Agents »

    Paramètres → Agents → Claude Code.

  2. Connectez un compte

    Chaque dossier de compte a sa ligne et son bouton « Connecter ». Si vous avez plusieurs comptes, cliquez sur « Tout connecter ». Vous pouvez les déconnecter un par un.

  3. Redémarrez les sessions

    PoDee ajoute des hooks à settings.json et garde une copie, settings.json.podee-backup. Les sessions de Claude Code déjà ouvertes les prennent en compte après un redémarrage.

  4. Regardez près de l’horloge

    Apparence → « À côté de l’horloge » : le travail de Claude s’affiche directement sur l’île fermée.

Agenda Google ou Outlook

PoDee lit votre agenda depuis un lien iCal. Pas besoin d’identifiant ni de mot de passe.

  1. Ajoutez un agenda

    Paramètres → Agenda → « Connecter un agenda ». Saisissez un nom et le lien iCal.

  2. Le lien Google

    Dans Google Agenda : Paramètres → votre agenda → « Intégrer l’agenda » → « Adresse secrète au format iCal ». Elle se termine par basic.ics. L’adresse publique ne fonctionne que si l’agenda est public.

  3. Le lien Outlook

    Dans Outlook : Paramètres → Calendrier → Calendriers partagés → « Publier un calendrier ». Choisissez le calendrier et « Peut afficher tous les détails », cliquez sur « Publier » et copiez le lien ICS.

  4. Rappels

    Les événements sont actualisés toutes les 15 minutes. Choisissez dans « Rappeler avant » combien de temps à l’avance vous prévenir d’une réunion.

Voix et chat IA

Commandes vocales, dictée et questions à l’IA, directement sur l’île.

  1. Choisissez la reconnaissance

    Paramètres → Voix → Reconnaissance. Whisper sur votre PC fonctionne sans internet : le modèle base pèse 150 Mo, small 490 Mo (notre choix), medium 1,5 Go. Il existe aussi Whisper dans le cloud avec une clé Groq gratuite, et la reconnaissance de Windows.

  2. Parlez

    Maintenez Ctrl+Alt+Espace et dites une commande, par exemple « ouvre Telegram ». Ctrl+Alt+D lance la dictée.

  3. Connectez le chat IA

    Paramètres → Chat IA → Fournisseur. Avec une clé d’API : « Obtenir une clé » ouvre la page du fournisseur, et la clé de Gemini est gratuite. Sans clé, le chat passe par un abonnement : Claude Code, Gemini CLI ou Codex.

  4. Où sont gardées les clés

    Dans le Gestionnaire d’identification Windows, pas dans le fichier de paramètres.

PoDoo + PoDee

Un téléphone avec PoDoo pilote l’île : il l’ouvre, lance un minuteur, ajoute des tâches et interroge PoDy.

  1. Installez PoDoo

    PoDoo s’installe sur le PC et sur le téléphone. Comment l’installer

  2. Activez la liaison

    Dans PoDee : Paramètres → Modules → « Lien avec PoDoo ». Les commandes ne sont acceptées que de PoDoo sur ce même PC.

  3. Pilotez depuis le téléphone

    Ouvrez la page PoDee dans PoDoo : l’île s’ouvre et se masque, minuteurs et tâches se règlent d’une touche. La réponse de PoDy arrive directement sur le téléphone.
