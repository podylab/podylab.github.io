Comment connecter le téléphone

PoDoo attend dans la zone de notification du PC. Le téléphone le trouve tout seul s’ils sont sur le même réseau.

  1. Par Wi-Fi

    Ouvrez l’appli sur le téléphone. Le PC avec PoDoo apparaît dans la liste : touchez-le, vérifiez que le code est le même sur le téléphone et sur le PC, puis autorisez la connexion sur le PC.

  2. Si le PC n’est pas trouvé

    Touchez « PC introuvable ? ». Vous pouvez scanner le QR code dans la fenêtre PoDoo, saisir les six chiffres affichés sur le PC ou entrer l’adresse à la main.

  3. Par câble USB

    Branchez le câble et activez « Partage de connexion via USB » sur le téléphone. Android le désactive chaque fois que le câble est débranché, alors activez-le à chaque fois. L’appli trouve ensuite le PC toute seule.

  4. Par Bluetooth

    Associez d’abord le téléphone au PC dans les paramètres de Windows. Choisissez ensuite Bluetooth sur le premier écran de l’appli. Le premier chargement prend quelques secondes.

Boutons et pages

Tout se règle sur le PC, à la souris. Le téléphone se met à jour aussitôt.

  1. Ajoutez un bouton

    Un bouton peut être une appli, un site, un dossier ou un fichier, un raccourci clavier, un script ou une suite d’actions. Les applis se glissent simplement sur la page.

  2. Créez une suite d’actions

    Plusieurs étapes sur un seul bouton : ouvrir un projet, lancer la musique, couper les notifications.

  3. Liez une page à une appli

    Choisissez des applis pour une page. Quand l’une d’elles est active sur le PC, le dock passe tout seul à cette page. Sans appli choisie, les pages se parcourent à la main.

  4. Choisissez un thème

    « Carnet de croquis », « Argile », « Console », « Affiche », « Verre » et d’autres. Vous pouvez mettre votre propre fond.

PoDoo + PoDee

Avec PoDee sur le PC, PoDoo affiche sa page. Depuis celle-ci, vous pilotez l’île de PoDee directement depuis le téléphone.

  1. Installez PoDee

    Il vous faut PoDee 1.3.5 et PoDoo 1.0.1 ou plus récent. Télécharger PoDee

  2. Activez la liaison dans PoDee

    Paramètres → Modules → « Lien avec PoDoo ». Rien à activer dans PoDoo lui-même.

  3. Ouvrez la page PoDee

    Elle apparaît toute seule dans le dock du téléphone. Ouvrir ou masquer l’île, lancer un minuteur, ajouter une tâche, interroger PoDy. La réponse de PoDy arrive sur le téléphone, et la conversation est conservée.

PoDee n’accepte de commandes que de PoDoo sur ce même PC.

Questions

Faut-il un compte ou internet ?

Pas de compte. Le téléphone et le PC doivent juste être sur le même réseau local, ou reliés par câble ou Bluetooth. PoDoo marche sans internet.

Ça marche sans le programme sur le PC ?

Non. L’appli du téléphone n’est que l’écran ; c’est le programme du PC qui agit. Le programme du PC est donc nécessaire.

Quels téléphones conviennent ?

N’importe quel téléphone ou tablette sous Android 7.0 ou plus récent. PoDoo n’a pas encore d’appli iPhone.

Que voit l’appli ?

Seulement le réseau et l’appareil photo, et l’appareil photo seulement pour scanner le QR code. Rien n’est envoyé ni à nous ni à personne.

Peut-on se connecter sans Wi-Fi ?

Oui. Branchez le téléphone au PC avec un câble USB ou associez-les en Bluetooth, puis choisissez cette option sur le premier écran de l’appli.
