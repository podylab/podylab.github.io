Как открыть настройки: запустите PoDee ещё раз из меню «Пуск». Второй остров не появится, откроются настройки уже работающей программы.

Claude Code на острове

Остров показывает, чем занят агент, и спрашивает вас, когда агенту нужно разрешение.

  1. Откройте «Агенты»

    Настройки → Агенты → Claude Code.

  2. Подключите аккаунт

    У каждой папки аккаунта своя строка и своя кнопка «Подключить». Если аккаунтов несколько, нажмите «Подключить все». Отключать можно по одному.

  3. Перезапустите сессии

    PoDee добавит хуки в settings.json и сохранит копию settings.json.podee-backup. Уже открытые сессии Claude Code подхватят их после перезапуска.

  4. Смотрите у часов

    Внешний вид → «Рядом с часами»: работа Claude будет видна прямо на закрытом острове.

Календарь Google или Outlook

PoDee читает календарь по ссылке iCal. Логин и пароль не нужны.

  1. Добавьте календарь

    Настройки → Календарь → «Подключить календарь». Впишите название и ссылку iCal.

  2. Ссылка из Google

    В Google Календаре: Настройки → ваш календарь → «Интеграция календаря» → «Закрытый адрес в формате iCal». Он заканчивается на basic.ics. Общедоступный адрес подойдёт, только если календарь открыт всем.

  3. Ссылка из Outlook

    В Outlook: Настройки → Календарь → Общие календари → «Опубликовать календарь». Выберите календарь и «Все сведения», нажмите «Опубликовать» и скопируйте ссылку ICS.

  4. Напоминания

    События обновляются каждые 15 минут. За сколько минут напомнить о встрече, выберите в «Напоминать за».

Голос и ИИ-чат

Команды голосом, диктовка и вопросы к ИИ прямо на острове.

  1. Выберите распознавание

    Настройки → Голос → Распознавание. Whisper на компьютере работает без интернета: модель base весит 150 МБ, small 490 МБ (советуем её), medium 1,5 ГБ. Ещё есть Whisper в облаке с бесплатным ключом Groq и распознавание Windows.

  2. Говорите

    Зажмите Ctrl+Alt+Space и скажите команду, например «открой Telegram». Ctrl+Alt+D включает диктовку.

  3. Подключите ИИ-чат

    Настройки → ИИ-чат → Провайдер. С ключом API: кнопка «Получить ключ» ведёт на страницу провайдера, у Gemini ключ бесплатный. Без ключа чат работает через подписку: Claude Code, Gemini CLI или Codex.

  4. Где лежат ключи

    В диспетчере учётных данных Windows, а не в файле настроек.

PoDoo + PoDee

Телефон с PoDoo управляет островом: открывает его, ставит таймер, добавляет задачи и спрашивает PoDy.

  1. Поставьте PoDoo

    PoDoo нужен на компьютере и на телефоне. Как поставить

  2. Включите связь

    В PoDee: Настройки → Модули → «Связь с PoDoo». Команды принимаются только от PoDoo на этом же компьютере.

  3. Управляйте с телефона

    Откройте в PoDoo страницу PoDee: остров открывается и прячется, таймер и задачи ставятся одним касанием. Ответ PoDy приходит прямо на телефон.
