Schritt für Schritt: Claude Code, Kalender, Sprache mit KI-Chat und die Verbindung zum Handy.

So öffnest du die Einstellungen: Starte PoDee noch einmal aus dem Startmenü. Es erscheint keine zweite Insel, sondern die Einstellungen der laufenden App.

Claude Code auf der Insel

Die Insel zeigt, woran der Agent arbeitet, und fragt dich, wenn er eine Erlaubnis braucht.

  1. Öffne „Agenten“

    Einstellungen → Agenten → Claude Code.

  2. Verbinde ein Konto

    Jeder Kontoordner hat seine eigene Zeile und seine eigene Schaltfläche „Verbinden“. Bei mehreren Konten klick auf „Alle verbinden“. Trennen kannst du sie einzeln.

  3. Starte die Sitzungen neu

    PoDee trägt Hooks in settings.json ein und legt die Kopie settings.json.podee-backup an. Bereits offene Sitzungen von Claude Code übernehmen sie nach einem Neustart.

  4. Schau neben die Uhr

    Aussehen → „Neben der Uhr“: Die Arbeit von Claude ist direkt auf der geschlossenen Insel zu sehen.

Google- oder Outlook-Kalender

PoDee liest den Kalender über einen iCal-Link. Login und Passwort sind nicht nötig.

  1. Füge einen Kalender hinzu

    Einstellungen → Kalender → „Kalender verbinden“. Trag einen Namen und den iCal-Link ein.

  2. Der Link aus Google

    In Google Kalender: Einstellungen → dein Kalender → „Kalender einbinden“ → „Privatadresse im iCal-Format“. Sie endet auf basic.ics. Die öffentliche Adresse funktioniert nur, wenn der Kalender für alle sichtbar ist.

  3. Der Link aus Outlook

    In Outlook: Einstellungen → Kalender → Freigegebene Kalender → „Kalender veröffentlichen“. Wähl den Kalender und „Kann alle Details anzeigen“, klick auf „Veröffentlichen“ und kopiere den ICS-Link.

  4. Erinnerungen

    Termine werden alle 15 Minuten aktualisiert. Wie früh du an ein Meeting erinnert wirst, stellst du unter „Erinnern vor“ ein.

Sprache und KI-Chat

Sprachbefehle, Diktat und Fragen an die KI direkt auf der Insel.

  1. Wähl die Erkennung

    Einstellungen → Stimme → Erkennung. Whisper auf dem PC läuft ohne Internet: Das Modell base hat 150 MB, small 490 MB (unsere Empfehlung), medium 1,5 GB. Außerdem gibt es Whisper in der Cloud mit einem kostenlosen Groq-Schlüssel und die Windows-Spracherkennung.

  2. Sprich

    Halte Strg+Alt+Leertaste gedrückt und sag einen Befehl, zum Beispiel „öffne Telegram“. Strg+Alt+D startet das Diktat.

  3. Verbinde den KI-Chat

    Einstellungen → KI-Chat → Anbieter. Mit API-Schlüssel: „Schlüssel holen“ führt zur Seite des Anbieters, bei Gemini ist der Schlüssel kostenlos. Ohne Schlüssel läuft der Chat über ein Abo: Claude Code, Gemini CLI oder Codex.

  4. Wo die Schlüssel liegen

    In der Windows-Anmeldeinformationsverwaltung, nicht in der Einstellungsdatei.

PoDoo + PoDee

Ein Handy mit PoDoo steuert die Insel: öffnet sie, stellt einen Timer, fügt Aufgaben hinzu und fragt PoDy.

  1. Installiere PoDoo

    PoDoo brauchst du auf dem PC und auf dem Handy. So installierst du es

  2. Schalte die Verbindung ein

    In PoDee: Einstellungen → Module → „PoDoo-Verbindung“. Befehle werden nur von PoDoo auf demselben PC angenommen.

  3. Steuere vom Handy aus

    Öffne in PoDoo die PoDee-Seite: Die Insel öffnet und versteckt sich, Timer und Aufgaben brauchen nur einen Tipp. Die Antwort von PoDy kommt direkt aufs Handy.
